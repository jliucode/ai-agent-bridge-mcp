# ai-agent-bridge-mcp

#### Description
agent之间的桥梁，互相通讯，联网跨域，互相指挥，互派任务：
1. 有炫酷网页界面显示各自的职责，claude code agent , autoClaw 等项目的名称，IP, 在线状态， 当前任务
2. 各个agent 从过sse mcp 协议链接到服务器
3. python 后端，vue 前端
4. 这个项目就是一个管理各上报的agent的服务
5. 有的agent的检索，有的是改bug，等
